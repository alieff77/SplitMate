# SplitMate — Setup Guide

## 1. Firebase Project

1. Go to [Firebase Console](https://console.firebase.google.com) → Create project
2. Enable **Firestore** (Native mode)
3. Enable **Firebase Auth** → Anonymous sign-in
4. Deploy Firestore rules: `firebase deploy --only firestore:rules`

## 2. FlutterFire Configuration

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

This regenerates `lib/firebase_options.dart` with your real project values.

## 3. Anthropic API Key

Edit `.env`:
```
ANTHROPIC_API_KEY=sk-ant-...
```

## 4. Run

```bash
flutter pub get
flutter run
```

## Project Structure

```
lib/
├── main.dart                   # Entry point
├── firebase_options.dart       # Generated by flutterfire configure
├── app/
│   ├── app.dart                # GetMaterialApp setup
│   └── routes/
│       ├── app_routes.dart     # Route name constants
│       └── app_pages.dart      # Route → View + Bindings
├── core/
│   ├── constants/              # Colors, theme
│   └── utils/                  # Currency, image compress, bill calc, settlement
├── models/                     # Pure data classes (fromMap/toMap)
├── services/                   # Firebase + Anthropic API calls
├── controllers/                # GetX state management (MVC Controller layer)
├── views/                      # Screens (MVC View layer)
└── widgets/                    # Reusable UI components
```

## Architecture

**MVC with GetX:**
- **Model** — `lib/models/` — immutable data classes with Firestore serialization
- **View** — `lib/views/` — StatelessWidgets using `Obx()` for reactive UI
- **Controller** — `lib/controllers/` — `GetxController` subclasses owning all state and business logic
- **Service** — `lib/services/` — thin Firebase/HTTP wrappers, no state
